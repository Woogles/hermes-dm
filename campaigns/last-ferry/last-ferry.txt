# The Last Ferry Lore

The campaign is set in a foggy harbor town called Marrowtide Harbor.

A ferry called the Last Ferry seems to arrive on nights that do not appear in official harbor records. People remember crossing it. Records say it never ran. Fog bells remember passengers who were never logged.

This is not campaign-wide time travel. It is a localized ferry memory echo.

## Core anomaly

The party must prove which ferry memories are:

- physical records
- witness memories
- fog echoes
- ledger edits
- faction tampering

## Safe anchors

- Ferry Landing
- Old Dock
- Tide Ledger
- Bell of Drowned Names
- Split Harbor

# Session 0: The Last Ferry

## Character guidance

For intermediate difficulty, allow moderate planning but keep beginner-friendly support.

Give each player:

- One favorite skill
- One trusted spell or feature
- One background:
  - Harbor hand
  - Ledger clerk
  - Tide witness
  - Ferry child

## Opening hook

Read to players:

> “A ferry has arrived on a night that does not appear in the ledger. People remember crossing it. The fog bell remembers names that were never logged. The Tide Guild says the harbor was always safe. The ledger says it was not. What is real: the memory, the record, or the fog?”

Then ask:

- What do you investigate first?
- Do you trust the ferry log or the witness?
- What can you prove?
